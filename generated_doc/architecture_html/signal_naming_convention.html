Convention format

Every signal name must follow this underscore-delimited pattern. The POSITION segment is optional when the device has a single unambiguous mounting location.

Naming rules

SYSTEM
  • 2–8 uppercase letters only (no digits)
  • Chosen once per functional sub-system
  • Stable across architecture releases
  • Examples: PBRK, AWD, DRVC, EFAN
Function
  • CamelCase: first letter uppercase
  • Abbreviated but self-explanatory
  • Avoid device brand / model numbers
  • May be compound: several underscore-separated CamelCase tokens count as one Function (Ext_Lifting)
  • May start with lowercase e for "electronic" (eTBA) or a leading ordinal digit (3rdCirc)
  • Examples: ActrPresr, CluPedlPosn, eTBA
POSITION (optional)
  • Omit when there is only one instance
  • Must be from the approved position list
  • Examples: LE, RI, RELE, FR
TYPE
  • 2–8 uppercase letters only
  • Describes component or signal interface
  • Must be from the approved type list
  • One mixed-case exception: Buz (buzzer)
  • Examples: SNSR, EVHS, HS, LS, REL, SIGN

Special cases — still compliant

These signal names look irregular at first glance but satisfy the convention.

Signal nameWhy it's compliant
FHIT_Ext_Lifting_SWTFunction spans two underscore-separated CamelCase tokens (Ext + Lifting) treated as one compound function.
TBRK_eTBA_EVHSFunction starts with lowercase 'e' meaning "electronic" (eTBA, eLSPmp1Ctrl) — the rest stays CamelCase.
FLDR_3rdCirc_EVHSFunction may start with a leading ordinal digit (3rdCirc) before the CamelCase text.
RDS_RvsMtn_BuzTYPE is normally 2-8 uppercase letters, but 'Buz' (buzzer) is a recognised mixed-case exception.

Automated validation

The validator runs automatically as Step 3 of the build pipeline (run.sh). It can also be invoked standalone:

# Validate against auto-detected architecture JSON
python3 tools/scripts/validate_signal_naming.py --root .

# Exit with code 1 when violations found (CI gate)
python3 tools/scripts/validate_signal_naming.py --root . --fail-on-warn
One warning per signal
Duplicate uses of the same non-compliant name are grouped into a single warning
Proposal included
Each warning includes a best-effort proposed name following the convention
Infra signals exempt
