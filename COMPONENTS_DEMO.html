✨ Résumé

Tous ces composants sont générés automatiquement par Python à partir du fichier JSON du projet. Aucune valeur hard-codée — tout est configurable.

Pour utiliser dans vos rapports :

from eec_ui_components import kpi_row, io_grid, flow_diagram, detail_panel

# Dans votre script Python
body = f"""
{kpi_row([...])}
{io_grid({...})}
{flow_diagram(...)}
{detail_panel(...)}
"""

out.write_text(html_page('Title', body, cfg), encoding='utf-8')
